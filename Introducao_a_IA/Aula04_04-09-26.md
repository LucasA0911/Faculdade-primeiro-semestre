- Data set = Conjunto de dados
 - Cuidados para montar o dataset
   - Vazamento de dados (Data leakage) é quando dados de treino, vão para os dados de testes e quando dados de validação já são conhecidos pelo algoritmo
   - Desbalanceamento de classes é quando uma situação acontece muito e outras acontecem pouca. A melhor proporção de situações é de 50-50. Podemos resolver esse problema utilizando as tecnicas de Oversampling(SMOTE) ou Undersampling
- Pipe line = sequencia fixa de um processo
- Outlier é= um dado que sai muito do padrão. *É importante não excluir e nem tentar colocar no padrão do dataset. O ideal é utilizar uma função de normalização.*
- Problema de gradiente(Overfitting) = um problema que ocorre quando o data set está mal processado e ele fica preso em números decimais muito pequenas.
--------------------------------------------------------------------------------
## Pipe line de aprendizado
- Features(Atributos) = Todos os atributos de entrada brutos coletados de diversas fontes que estão entrando em uma rede neural
- Pré processamento = Parte do tratamento, limpeza, transformação e padronização dos dados
  - Limpeza e imputação = tratamento dos dados ausentes, eliminação de registros duplicados e remoção de ruidos do data set
    - Valores ausentes podem ser tratados removendo linhas colunas ou preenchendo-os via imputação
    - Estratégias de imputação = média, mediana, moda  ou algoritmos preditivos
    - Identificação de outliers = identeificação e atenuação de valores discrepantes que distorcem o aprendizado
    - Eliminação de inconsistencias = correção de erros de digitação e padronização de datas e formatos.
  - Normalização e escala = Ajuste de grandes faixas numéricas para garantir que atributos não dominem indevidamente o algoritmo
    - Os dados devem ser dimensionados pois atributos em escalas diferentes podem causar vicios no algoritmo.
    - Normalização (min-max scaling)
    - Padronização (Z-score normalization)
    - Algoritmos afetados = essencial para redes neurais, KNN, SVM e algoritmos baseados em distância
  - Tokenização e codificação = Conversão de textos, categorias e dados não estruturados em vetores e matrizes numéricas.
- Modelo & saída = Treinamento do algoritmo matemático com dados tratados para gerar inferencias, classificações ou regressões precisas
- Não pode cair no *garbage in, garbage out*, que basicamente é entrada de lixo e saida de lixo. 
--------------------------------------------------------------------------------
## Divisão do dataset
- Conjunto de treino =  utiliza de 60% a 80% dos dados para aprender padrões e otimizar os parâmetros
- Conjunto de validação = Utiliza de 10% a 20% dos dados para ajustar hiperparâmetros e monirotar o overfitting.
- Conjunto de teste = Utiliza de 10% a 20% de dados nunca vistos pelo modelo, usados para avaliar o desempenho real.
--------------------------------------------------------------------------------
## Matriz de confusão
- Verdadeiro positivo = Um retorno positivo do algoritmo que realmente era positivo
- Falso positivo = Um retorno positivo do algoritmo que não era positivo
- Verdadeiro negativo = Um retorno negativo do algoritmo que realmente era negativo
- Falso negativo = Um retorno negativo do algoritmo que não era negativo
