## Estruturas complexas - 
- Conjuntos(Set)
*É uma coleção não ordenada de elementos únicos e mutável que usa hashing internamente para operações rapidas.*

Ex:
a = {6,7,8,9,9,8,6,6,6}
print(a) # {8,9,6,7}

- Operações
add() - Adiciona um elemento ao conjunto
update() - Adiciona multiplos elementos
remove() - Remove um elemento do conjunto
discard() - Remove um elemento(Não gera erro se o elemento não exister)
pop()
intersection() = &
union() = |

## Match
*Uma instrução Match é usada para implementar o Pattern Matching (correspondência de padrões). Pense nela como uma evolução muito mais poderosa e elegante do tradicional switch/case de outras linguagens.
Com o match, você pode comparar um valor (ou objeto) contra vários padrões diferentes e executar o bloco de código correspondente ao primeiro padrão que corresponder.* (Estudar mais sobre)
