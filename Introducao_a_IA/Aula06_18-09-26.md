Api = Aplicação de sistema de inteface. Ela conecta um sistema no outro

Metodos Get, Post e Delete

Get passa os valores na url
Recebe no PHP da seguinte forma:
$user = $_GET["usuário"]
$password = $_GET["Senha"]

Post passa os valores em um JSON
Recebe no PHP da seguinte forma:
$user = $_POST["usuário"]
$password = $_POST["Senha"]
