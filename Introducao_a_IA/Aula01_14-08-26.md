# O que é IA

IA é qualquer tecnica que imita o comportamento humano
ML é um subconjunto que aprende padrões a partir de dados sem programação explicita, geralmente utiliza padrões matemáticos
DL é um subconjunto de ML que usa redes neurais profundas para dados não estruturados.

# Redes neurais e Perceptron

Uma rede neural faz o mesmo processo dos neuronios em um cérebro, onde cada neuronio faz um calculo matemático para ter um resultado proximo de 100% de acerto
Perceptron é basicamente o neuronio de uma rede neural, onde ele recebe um dado, faz o calculo e tem uma saida.
Esse calculo de soma ponderada é basicamente este: 
#### **Z - (w1.x1) + (w2.x2) + ... + (Wn.Xn)+b**
 - X = dados de entrada
 - W = pesos que definem a importância de cada entrada
 - B = viés(bias), que ajusta o limiar de ativação

Função de ativação é o que você faz com o resultado do calculo. Geralmente se utiliza um degrau de Heaviside.
Exemplo:
    y=1 se Z >= 0
    y=0 se Z < 0
Esse exeplo é um degrau de Heaviside.
