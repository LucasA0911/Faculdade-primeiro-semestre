## List compression

lista = [1,3,4,5]
lista = [i + 1 for i in lista]
print(lista)

Ele faz um looping do tamanho da lista criada anteriormente, e retorna o resultado da operação de i + 1, ou i * 1 ou 1 / 1, etc...

# Funções recursivas

São funções que chamam elas mesmas para resolver um problema. A ideia é dividir um problema maior em problemas menores.

def contagem(n):
    if n == 0:
        print("Fim!")
    else:
        print(n)
        contagem(n - 1)
contagem(10)

def fibonacci(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))
